# Round cost

What a review round's model calls cost, from a price per model in the owner's config ([Budget and model planner](../design/05-architecture/06-budget-and-model-planner.md): a model missing from the table shows no price, never an estimate). The cost plan task T13's `intakt:review` prints; issue #1107 part 1 (the console), the dashboard's cost line being part 2.

- **Config:** `budget.prices.<model>` in `config/intakt.yaml`, beside the ceilings, processed by `Core/Budget/Infrastructure/BudgetConfiguration` (formerly `CeilingsConfiguration`, see [Measured use](measured-use.md)): keys not normalized, so a model name keeps its dashes and dots; `input` and `output` required, `cache_read` and `cache_write` optional and set to `input` when left out; each a float of at least 0, in US dollars per million tokens; an int becomes a float, and a NaN or infinite float becomes a string before normalization so the type check refuses it (Symfony Config skips every check for NaN, see `upstream/config-nan-skips-validation/`). `config/packages/ai.php` puts the result in the parameter `intakt.budget.prices` (`BudgetServices::PRICES`). No `prices` key means an empty table.
- **Contract:** `Core/Budget/Contract/Prices::costOf(?string $model, TokenFigures $figures): Cost`. `Cost` holds `usd` (a float, or null when unknown) and `unpriced` (the models without a price, each once). `Cost::plus()` adds two known costs; a known plus an unknown is unknown and keeps the models of both, so a round with one unpriced call never shows a partial sum or 0. `Cost::none()` is 0 (a round without calls).
- **Implementation:** `Core/Budget/Infrastructure/ConfiguredPrices` reads the parameter. For a model in the table the cost is `(prompt - cacheRead - cacheWrite) * input + cacheRead * cache_read + cacheWrite * cache_write + completion * output`, divided by a million, on the `TokenFigures` of [Vendor](vendor.md#token-figures); the combined `cached` figure (Claude Code) stays in the input part, because it does not say which of the two cache prices applies. A model not in the table, and a call whose `started` row has no model (named `ConfiguredPrices::NO_MODEL`, `(no model)`), give `Cost::unknown(model)`.
- **A round's cost:** `Core/Review/UseCase/ReviewChange/RoundLedgerReading::costOf(roundId)` finds the round's calls exactly as `tokensOf()` does (the `started` `usage_recorded` rows carrying the round id, and the `settled` or `unsettled` row of each call) and prices the summed `TokenFigures` of each call's usage entries by the `model` of the call's `started` row (the model its tier resolved to, see [Vendor](vendor.md)), because a round's reviewers and its judge may run on different models, and the `model` of a usage entry is what the vendor's answer names: none for Claude Code and Codex, a dated snapshot such as `gpt-5-2025-08-07` for an API. A call with no usage entries adds 0. `ReviewChange` puts it on `Contract/ChangeReview::$cost`. A recorded loop round (`Core/Shadow/Infrastructure/RecordedHead`) carries `Cost::unknown()` with no model, because the recording keeps no models.
- **Console:** `Plugin/LocalGitForge/UseCase/ReviewChange/ReviewReport` prints `cost: 0.0459 USD` (four decimals) after the token line, or `cost: unknown, no price for <models>` (each model name through `VisiblePath`, because a model name comes from the ledger), or `cost: unknown` when no model is named. The JSON (`ReviewOutput`) carries `cost` with `usd` and `unpriced` (`docs/user/review-output.schema.json`).
- **Not yet:** the price table is not dated and prices are not fixed when a call is admitted (the design's dated table); the dashboard still says `no price`.
- **Tests:** `tests/Core/Budget/Contract/CostTest.php`, `tests/Core/Budget/Infrastructure/ConfiguredPricesTest.php` (a recorded Anthropic usage answer through Symfony AI's Anthropic `TokenUsageExtractor`, priced and unknown; an OpenAI-form answer; unsplit cached tokens; a row without a model), `tests/Core/Budget/Infrastructure/BudgetConfigurationTest.php`, `tests/Core/Review/UseCase/ReviewChange/RoundLedgerReadingTest.php` (a Claude Code answer through its `TokenUsageExtractor`, which names no model, and an API answer naming a dated snapshot, both priced by the tier's model; a call started without a model) and `ReviewChangeTest.php`, `tests/Plugin/SymfonyAiVendor/SymfonyAiVendorTest.php` (the started row names the tier's model, or the substitute's), `tests/Plugin/LocalGitForge/ReviewChangeCommandTest.php` and `ReviewOutputTest.php`, and `tests/Application/ProjectTiersTest.php` (the file's prices reach the parameter).
