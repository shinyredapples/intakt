# Retried network git calls

`NetworkGit::run(GitCall)` (`src/Core/Git/Contract/`) runs a read-only network git call. If it fails it waits 10 seconds (`ClockInterface::sleep()`) and tries again, then waits 30 seconds and tries a last time. Each wait is logged as a warning with the attempt, the delay and git's message. After the third failure it throws `NetworkGitFailed` ("git failed after 3 attempts: ..." followed by git's own error text). A call is limited to 600 seconds per attempt (the constructor's `timeoutSeconds`, which the tests lower). An attempt that hits that limit, is killed by a signal or cannot start counts as a failed attempt and is retried the same way; its reason joins git's message in Intakt's own words (`git timed out after 600 seconds`, `git was killed by signal <n>`, `git could not start`). The message of Symfony Process's exception is never used, because it holds the whole command line, and with it any credential in the remote's URL, which would otherwise reach the logged warnings and `NetworkGitFailed`. `NetworkGit::run(GitCall)` repeats the same call; `NetworkGit::runEachAttempt(Closure)` builds the call again before each attempt.

A `GitCall` from `HardenedGit` allows no transport protocol, so `NetworkGit` overrides just two variables of the call it runs: `GIT_ALLOW_PROTOCOL=file:https` and `GIT_TERMINAL_PROMPT=0` (git never asks for a password). The work tree is the caller's: a call on a mirror comes from `HardenedGit::callInBareRepository()`, which takes none, and `clone --mirror` keeps the work tree `call()` pins to the folder it runs in, which a mirror clone does not use.

Only calls that read from a remote go through `NetworkGit`: a retried write could happen twice. Its caller is `UpdateMirror` (`src/Core/Git/UseCase/UpdateMirror/UpdateMirror.php`), which keeps the bare mirror per project (`docs/architecture/mirror.md`): its `clone --mirror`, both fetches and `ls-remote` run through `NetworkGit`.

The tests (`tests/Core/Git/Contract/NetworkGitTest.php`) prove the delays with a clock that records each sleep and never waits (`tests/Core/Git/RecordingClock.php`); one test makes the remote appear during the first sleep to prove that a call that fails once succeeds on the retry, and one times out on every attempt (a 0.2-second limit) with a credential in the remote's URL and checks that the credential is in neither the warnings nor the failure.
