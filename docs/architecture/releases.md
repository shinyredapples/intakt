## Releases

`.github/workflows/release-labels.yml` labels each pull request `feat`, `fix` or `docs` from its title type and removes a stale one, reading the labels at run time. It runs when a pull request is opened, reopened or gets a new push (`opened`, `reopened`, `synchronize`), never on an edit, so a title edit alone changes no label until the next push. `.github/release.yml` groups the generated notes by those labels. `tests/Gates/ReleaseLabelsTest.php` runs the workflow script against a fake `gh`, and `tests/Gates/ReleaseLabelsTriggersTest.php` asserts the workflow's `on:` block. Details: [Releasing](../releasing.md).
