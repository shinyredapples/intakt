Point 3 ("the `MessageBagNormalizer` can stay as it is") is not enough with resume alone. Two user messages after the last assistant message still lose the first, and one `Message::ofUser('The task: FIRST', 'The diff: SECOND')` keeps only its first text block, because both the Codex and the ClaudeCode normalizer stop at the first text block of the last user message (`break 2`). On BETA1 (still on `main` 6747a33) the two cases give the prompts `"The diff: SECOND"` and `"The task: FIRST"`. Joining the text blocks of every user message after the last assistant message, in order, would cover both.
